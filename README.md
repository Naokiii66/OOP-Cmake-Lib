# Банкомат: бібліотека класів

Бібліотека класів предметної області "Банкомат" на C++ з використанням CMake.

Ієрархії:
- `BankCard` -> `DebitCard`, `CreditCard` (банківські картки)
- `Terminal` -> `ATM` (термінали самообслуговування)

Структура:
- `lib/include` - заголовкові файли
- `lib/src` - реалізація бібліотеки
- `src/main.cpp` - демонстрація

Збірка:
```
cmake -S . -B build
cmake --build build
./build/atm_app
```
